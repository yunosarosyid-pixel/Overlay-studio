Cara pasang di OBS Studio

  1. Klik Buat link overlay, lalu salin link yang muncul.
  2. Di OBS: Sources → tombol + → pilih Browser Source.
  3. Tempel link tadi ke kolom URL.
  4. Atur Width & Height sesuai canvas Anda (misal 1080 x 1920 untuk vertikal TikTok/Reels atau 1920 x 1080).
  5. Klik OK. Overlay otomatis tampil transparan.
