Cara pasang di OBS

  1. Klik Buat link overlay, lalu salin link yang muncul.
  2. Di OBS: Sources → tombol + → pilih Browser.
  3. Tempel link tadi ke kolom URL.
  4. Atur Width & Height sesuai ukuran vertical Anda, misalnya 1080 x 1920.
  5. Centang Shutdown source when not visible tidak perlu dicentang agar animasi tetap jalan.
  6. Klik OK. Overlay langsung tampil transparan di atas kamera.
